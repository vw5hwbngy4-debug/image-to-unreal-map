# Image to Unreal Map

Preserved SpawnMap.ai experiment: a visual reference was used in a GPT-assisted workflow to construct a playable Unreal Engine 1 / Tactical Ops map.

This repository preserves the browser experience together with the generated map artifacts, including T3D source, compiled UNR map, provenance material, iterations, and recorded runtime evidence.

## GitHub Pages

The static archive is designed to run from this repository at `/image-to-unreal-map/`. Live PHP telemetry/server-status endpoints from the original Hostinger deployment are preserved only where present as historical source and are not required for the static map/viewer experience.

## Project name

SpawnMap.ai is the original project identity. `image-to-unreal-map` is the descriptive repository name for this preserved experiment.
